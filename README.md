# Datheon Machine Learning & Data Science Internship

## Task 1 · Iris species classification

Open `task_01_iris/Iris_Classification.ipynb` to view the executed benchmark and charts. The notebook loads the bundled scikit-learn Iris dataset and compares two classifiers on the same stratified 80/20 split (seed 42). It includes class-level reports, a macro-average comparison, confusion matrices and two-feature decision regions.

### Run locally

From this folder, run the following with Python 3 in a virtual environment.

```bash
python -m pip install -r requirements.txt
python -m jupyter lab task_01_iris/Iris_Classification.ipynb
```

In Jupyter, choose **Run → Run All Cells**. No dataset download is required.
